# Structure

- `www/` — copied frontend files used by the Android wrapper.
- `package.json` — Capacitor commands.
- `capacitor.config.json` — app ID/name and web directory.
- `../formfit_api.py` — Python backend.
- `../pose_engine.py` — pose detection.
- `../form_intelligence.py` — form analysis.
- `../recommendation_engine.py` — recommendations.

Keep a backup before changing active AI files.
