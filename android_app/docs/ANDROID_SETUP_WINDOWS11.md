# FormFit Android setup — Windows 11

1. Install Node.js 22+ and Android Studio.
2. Open this `android_app` folder in VS Code.
3. Run `npm install`.
4. Run `npm run android:add`.
5. Run `npm run android:sync`.
6. Run `npm run android:open`.
7. In Android Studio, select an emulator or USB-debugging phone and press Run.

The Python AI backend remains in the parent `formfit_v2` folder. The Android wrapper does not replace the pose engine.
