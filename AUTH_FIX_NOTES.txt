FORMFIT AUTH FIX

Problem fixed:
SQLite registration used INSERT ... RETURNING id. The cursor remained active when the DB context manager committed, causing:
  sqlite3.OperationalError: cannot commit transaction - SQL statements in progress
This could then cause:
  sqlite3.OperationalError: database is locked

Fix:
- SQLite registration now uses a normal INSERT and cursor.lastrowid.
- PostgreSQL keeps INSERT ... RETURNING id.
- Login/session behavior is unchanged.
- No frontend/UI or pose-engine files were intentionally changed.
